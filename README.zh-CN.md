# 长夜幻境 Web（EvernightRealm Web）

> 长夜幻境的客户端界面——用浏览器或桌面客户端，走进属于你小圈子的私密世界。

[English](./README.md) · [简体中文](./README.zh-CN.md) · [繁體中文（台灣）](./README.zh-TW.md) · [日本語](./README.ja-JP.md)

## 这是什么？

这是长夜幻境的客户端。长夜幻境是一个自主部署、离线优先的平台，面向小规模玩家群体。活动、角色、资产与聊天都在这里呈现——全部在局域网内完成，不需要公网、云账号或遥测。

## 功能规划（开发中）

- **活动视图**：跟随场景、阶段与事件的发展
- **角色面板**：玩家、NPC 与管理员的身份，共处一个私密世界
- **资产管理**：查看与交易虚拟物品，归属可审计
- **私密聊天**：消息只留在你自己的服务器上
- **离线优先**：客户端完全对接你的本地服务器，不依赖云服务

## 当前状态

正在积极开发中，尚未发布稳定版本。

## 发布后的使用方式（规划）

- 在同一局域网内用浏览器打开主机地址即可加入，无需安装
- 也将提供 Windows、macOS、Linux 桌面客户端
- 无需第三方注册；数据只保存在主机上

## 界面语言

简体中文、繁体中文（台湾）、English、日本語。界面语言默认跟随系统语言，可在服务器入口页切换并记住选择；系统语言不在支持列表时回退 English。

## 服务器连通性检查

服务器入口页提供“服务器连通性检查”：向你的服务器读取健康与时间端点，显示服务名与版本、服务器的 UTC 时间、按服务器显示时区换算后的当地时间，以及本次请求的识别码。检查失败时界面只说明失败原因（无法连接、没有回应、服务尚未就绪等）并给出错误码与请求识别码，不会留下任何看起来像成功的数据；所有数值都来自服务器，不使用本机时钟或示例数据。

## 服务器地址

服务器入口页可以直接输入要使用的服务器地址并保存在本机，切换测试服务器不再需要重新构建。只接受完整的 `http://` 或 `https://` 地址（不得包含用户名或密码），并且必须连得通才会保存：格式不合格时按具体原因提示（例如“地址需要以 http:// 或 https:// 开头”）并且完全不发出请求；格式合格但连不通时不保存，并说明原因而不是假装成功。界面把“当前使用的地址”和“本机已保存的地址”分开列出，并说明当前值从何而来；调试构建下编译期参数 `--dart-define=ER_SERVER_BASE_URL` 优先，此时界面会明确告知本机保存的地址尚未生效。你输入的内容只保存在自己的设备上。

## 界面出错时

如果应用某一部分无法正常显示，界面会切换到一个安全的提示页面：说明问题发生的位置（界面绘制、后台任务或与服务器往来）、一个用于对照本机日志的诊断码，以及服务器请求的关联 ID（如果与请求有关）。你可以按“返回可用页面”回到可使用的界面。提示页面不会显示错误原文、程序堆栈或服务器地址，也不会把任何内容发送到外部——问题只记录在你自己的设备上。

需要说明的是：刚刚出错的那一块在返回后可能短暂留白，要等界面下一次重建才会恢复；如果同样的问题反复出现，提示页面会建议你重新载入应用。
